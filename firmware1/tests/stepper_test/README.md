# stepper_test — 카드 이송 스텝 모터 시험

카드 이송 모터 (pins.h: `PIN_TAPE_*`) 가 드라이버(STEP/DIR/EN)로 제대로 도는지, 1mm 가 몇 스텝인지 잰다.

## 연결

| Mega 핀 | 드라이버 (A4988·DRV8825 계열) |
|---|---|
| D40 (pins.h: `PIN_TAPE_STEP`) | STEP |
| D41 (pins.h: `PIN_TAPE_DIR`) | DIR |
| D42 (pins.h: `PIN_TAPE_EN`) | EN (LOW = 켜짐) |
| GND | GND (드라이버 로직 GND, **모터 전원 GND 와 공통**) |

- 드라이버 모터 전원(VMOT)은 배터리, 로직 전원(VDD)은 Mega 5V.
- 처음에는 **카드를 빼고, 모터가 기구에 걸리지 않게** 둔 채 시험한다.
- pins.h 의 "L298N 임시 연결"(4선) 방식은 이 시험이 다루지 않는다.
- **업로드할 때는 배터리를 빼고 USB 만.**

## 올리기

```bash
cd firmware1/tests/stepper_test
pio run -t upload
pio device monitor
```

## 시리얼에서

| 입력 | 동작 |
|---|---|
| `s` | 한 스텝 (마지막 방향) |
| `f` / `b` | 한 바퀴 앞으로 / 뒤로 |
| `+` / `-` | 속도 ±50 스텝/초 (50~1000) |
| `m25` / `m-10` | 25mm 앞으로 / 10mm 뒤로 (한 번에 최대 300mm) |
| (이동 중 아무 키) | 멈춤 |
| `?` | 도움말과 지금 설정 |

- 움직이기 직전에만 EN 을 켜고 **끝나면 바로 끈다** (발열 방지). 그래서 멈춰 있을 때는 손으로 돌려진다.

## 성공이면

- `s` 를 누를 때마다 축이 조금씩(1.8°) 돈다. `f` → 정확히 한 바퀴, `b` → 반대로 한 바퀴.
- 각 이동 뒤에 `앞으로 200스텝 = 약 40.0mm, 1.00바퀴 (EN 꺼짐)` 같은 줄이 나온다.
- 방향이 거꾸로면 `src/main.cpp` 맨 위 `DIR_FORWARD` 를 `LOW` 로 바꾼다.
- 떨기만 하고 안 돌면: 속도를 `-` 로 낮추거나, 모터 코일 두 쌍의 배선·드라이버 전류(가변저항)를 확인한다.

## 실측해서 고치기 (맨 위 상수)

| 상수 | 지금 (임시값) | 어떻게 정하나 |
|---|---|---|
| `STEPS_PER_REV` | 200 | 모터 사양. 1.8° 모터 = 200, 0.9° 모터 = 400. `f` 가 정확히 한 바퀴면 맞다 |
| `MICROSTEPS` | 1 | 드라이버 MS1~MS3 핀 설정 (연결 안 하면 1). 바꾸면 `STEPS_PER_MM` 도 같은 배수로 바꾼다 |
| `STEPS_PER_MM` | 5.0 | 아래 방법으로 잰다 (5.0 은 롤러 지름 약 12mm 를 가정한 값) |
| 속도 | 200 스텝/초 | 카드가 미끄러지지 않고 소리가 덜 나는 빠르기를 `+`/`-` 로 찾는다 |

**`STEPS_PER_MM` 재는 법**

1. 카드를 넣고 끝에 표시를 한다.
2. `m100` (100mm 앞으로) — 이때 보낸 스텝 수 = 100 × 지금 `STEPS_PER_MM`.
3. 카드가 실제로 움직인 거리를 자로 잰다 (예: 87mm).
4. 새 값 = 지금 값 × 100 ÷ 실제 거리. 예) 5.0 × 100 ÷ 87 = **5.75**
5. `STEPS_PER_MM` 을 고쳐 다시 올리고 `m100` 으로 다시 확인한다 (±1mm 안이면 충분).
