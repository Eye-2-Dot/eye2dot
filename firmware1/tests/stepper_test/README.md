# stepper_test — 스텝 모터 2개 시험 (헤드, 카드 랙)

스텝 모터(28BYJ-48)가 ULN2003 보드로 제대로 도는지, 방향이 맞는지, 1mm 가 몇 스텝인지 확인한다.

- 모터 A = **헤드** (GT2 벨트 + 20잇 풀리)
- 모터 B = **카드 랙** (랙 + 20잇 피니언 — 카드 한 장을 고정 벽까지 미는 축)

스텝 수·방향은 완성 펌웨어와 같은 [`mega/include/motion.h`](../../mega/include/motion.h) 값을 쓴다.
**이 시험 코드에는 고칠 숫자가 없다** — 값이 다르면 `motion.h` 를 고치고, 이 시험과 `mega` 를 다시 올린다.

## 연결

| Mega 핀 | ULN2003 보드 |
|---|---|
| D36 / D37 / D38 / D39 (pins.h: `PIN_HEAD_IN`) | 헤드 보드 IN1 / IN2 / IN3 / IN4 |
| D40 / D41 / D42 / D43 (pins.h: `PIN_CARD_IN`) | 카드 랙 보드 IN1 / IN2 / IN3 / IN4 |
| D34 (pins.h: `PIN_HEAD_LIMIT`) | 원점 스위치 NO (COM 은 GND) |
| GND | 두 보드의 − (**벅 컨버터 GND 와 공통**) |

- 보드의 **+ 는 벅 컨버터의 5V** 에 연결한다. Mega 의 5V 핀에서 끌어오면 전류가 모자라 Mega 가 꺼졌다 켜질 수 있다.
- 모터의 흰 5핀 커넥터는 보드의 흰 소켓에 꽂는다 (한 방향으로만 들어간다).
- 처음에는 **벨트·랙을 풀어 모터가 기구에 걸리지 않게** 둔 채 시험한다.
- 이 시험은 원점 스위치를 **읽어 보여 주기만** 한다. 스위치에서 멈추지 않으니 기구에 물린 뒤에는 짧게 움직일 것.
- **업로드할 때는 배터리를 빼고 USB 만.**

## 올리기

```bash
cd firmware1/tests/stepper_test
pio run -t upload
pio device monitor
```

## 시리얼에서

| 입력 | 동작 |
|---|---|
| `a` | 축 바꾸기 (헤드 ↔ 카드 랙). 처음은 헤드 |
| `s` | 한 스텝 (마지막 방향) |
| `f` / `b` | 한 바퀴 + 방향 / − 방향 (약 6~8초) |
| `+` / `-` | 속도 ±50 스텝/초 (100~750) |
| `m25` / `m-10` | 25mm + 방향 / 10mm − 방향 (한 번에 최대 150mm) |
| `l` | 원점 스위치(D34) 상태 |
| (이동 중 아무 키) | 멈춤 |
| `?` | 도움말과 지금 설정 |

- **+ 방향** = 헤드는 원점 스위치에서 **멀어지는** 쪽, 카드 랙은 **카드 고정 벽** 쪽.
- 움직이는 동안에만 코일을 켜고 **끝나면 바로 끈다** (발열 방지). 감속 기어 때문에 꺼도 그 자리에 있다.
- 보드의 LED 4개가 차례로 깜빡이면 신호는 가고 있는 것이다.

## 성공이면

- `f` → 출력축이 정확히 한 바퀴, `b` → 반대로 한 바퀴. 축에 테이프를 붙여 두면 보기 쉽다.
- 각 이동 뒤에 `헤드(모터 A) + 방향 4076스텝 = 약 40.0mm, 1.00바퀴 (코일 꺼짐)` 같은 줄이 나온다.
- 기구에 물린 뒤: `m10` 이 헤드를 스위치에서 **멀어지게**, 랙을 벽 **쪽으로** 보낸다.
  반대면 `motion.h` 의 `HEAD_DIR_INVERT` / `CARD_DIR_INVERT` 를 `true` 로.
- LED 는 깜빡이는데 모터가 떨기만 하면: IN1~IN4 순서가 바뀌었는지 보고, `-` 로 속도를 낮춘다. 보드 전원이 5V 인지도 확인한다.
- LED 가 안 켜지면: Mega 핀 번호와 GND 공통을 확인한다.

## 실측해서 고치기 (`motion.h`)

| 상수 | 설계값 | 어떻게 정하나 |
|---|---|---|
| `MOTOR_STEPS_PER_REV` | 4076 | 28BYJ-48 의 하프 스텝 수. `f` 가 정확히 한 바퀴면 맞다 (기어비가 다른 판이면 4096 일 수 있다) |
| `HEAD_STEPS_PER_MM` | 101.9 | GT2 20잇 풀리: 4076 ÷ 40mm |
| `CARD_STEPS_PER_MM` | 64.87 | 20잇 피니언(피치원 지름 20mm): 4076 ÷ 62.83mm |
| `*_MAX_SPEED_MM_S` | 헤드 7, 랙 10 | 이 시험에서 `+` 로 올려 가며 떨지 않고 도는 가장 빠른 속도의 80% 쯤 |

**거리 확인하는 법** (벨트·랙은 미끄러지지 않으므로 보통 계산값 그대로 맞는다)

1. 헤드(또는 랙) 옆에 자를 대고 지금 자리를 표시한다.
2. `m50` (50mm + 방향).
3. 실제로 움직인 거리를 잰다 (예: 49mm).
4. ±0.5mm 안이면 그대로 둔다. 다르면 새 값 = 지금 값 × 50 ÷ 실제 거리.

그다음 순서(카드 공급 거리, 첫 칸 자리)는 완성 펌웨어의 USB 명령으로 한다 — [`firmware1/README.md`](../../README.md) "시험 방법 5".
