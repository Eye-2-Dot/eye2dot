# solenoid_test — 솔레노이드 6개 시험

솔레노이드 6개가 각각, 그리고 동시에 제대로 찍히는지와 번호(배선 순서)가 맞는지 본다.
`firmware2/tools/solenoid_mask_test/solenoid_mask_test.ino` 를 PlatformIO 로 옮긴 것이다.

## 연결

| Mega 핀 | 연결 | 솔레노이드 |
|---|---|---|
| D22~D27 (pins.h: `PIN_SOL`) | L298N #1 IN1~IN4, #2 IN1~IN2 | 1~6번 |

- **솔레노이드 1번(D22) = 위에서 볼 때 왼쪽 위.** 1·2·3번이 왼쪽 열, 4·5·6번이 오른쪽 열(위→아래).
- L298N 은 배터리(약 11.1V)로, Mega 와 **GND 공통**. ENA·ENB 점퍼는 꽂은 채로.
- D22~D27 에 각각 **10kΩ 풀다운 → GND** 를 권장한다 (리셋·업로드 중 솔레노이드가 켜지는 것 방지).
- **업로드할 때는 배터리를 빼고 USB 만.** 올린 뒤 배터리를 연결한다.

## 올리기

```bash
cd firmware2/tests/solenoid_test
pio run -t upload        # 배터리 뺀 상태로
pio device monitor
```

## 시리얼에서

| 입력 | 동작 |
|---|---|
| `0`~`63` + Enter | 그 비트의 솔레노이드를 **동시에** 한 칸 찍기 (`SOL_STRIKES` 번 누름) |
| `y` + Enter | 1번 → 6번 하나씩 (0.4초 간격) |
| `?` | 도움말 |

- 켜는 시간·누르는 횟수·쉬는 시간은 완성 펌웨어와 같은 `mega/include/solenoid.h` 의 `SOL_PULSE_MS`(30ms)·`SOL_STRIKES`(2번, 사이 `SOL_RESTRIKE_GAP_MS` 60ms)·`SOL_COOLDOWN_MS`(200ms) 다. 종이가 두꺼워서 한 칸을 두 번 누른다.
- **과열 방지**: 최근 10초 동안 40번을 넘게 찍으면 "과열 방지: … 초 뒤에 다시 하세요" 하고 찍지 않는다.

## 성공이면

1. `1` → **1번(위에서 볼 때 왼쪽 위)** 만 "딸깍".
2. `y` → 1·2·3번(왼쪽 열 위→아래), 4·5·6번(오른쪽 열 위→아래) 순서로 하나씩.
3. `63` → 6개가 **한꺼번에** "딸깍" 한 번.

번호가 다르면 L298N 출력 ↔ 솔레노이드 배선을 바꾼다. **펌웨어에서 뒤집어 맞추지 말 것** (거울 변환은 서버만 한다).
솔레노이드가 계속 켜져 있거나 뜨거워지면 바로 배터리를 뺀다.
